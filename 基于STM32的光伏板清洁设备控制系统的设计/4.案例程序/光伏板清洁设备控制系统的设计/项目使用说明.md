# 基于STM32的光伏板清洁设备控制系统使用说明

## 1. 项目用途
本系统用于光伏板清洁设备的本地控制与状态监测。系统以 STM32 作为主控制器，结合光照传感器、电流检测模块、直流电机、OLED 显示屏、按键和 ESP8266 Wi-Fi 模块，实现以下功能：

- 自动判断光伏板是否可能因积灰导致发电能力下降。
- 在满足条件时自动启动清洁。
- 支持手动启动/停止清洁。
- 支持按时间间隔定时清洁。
- 夜间自动禁止自动/定时清洁，避免无效运行。
- 在 OLED 上实时显示运行状态和关键参数。
- 通过 Wi-Fi 将状态推送给手机端或上位机查看。

## 2. 系统使用前准备
1. 确认主控板、光照传感器、INA226 电流检测模块、电机驱动、OLED 和 ESP8266 模块已正确连接。
2. 上电后等待设备初始化完成。
3. 若需要手机查看状态，手机端连接设备热点：
   - SSID：`ESP8266_AP`
   - 密码：`12345678`
   - IP：`192.168.4.1`
   - 端口：`5000`

当前 Wi-Fi 功能主要用于状态查看，设备会按固定周期向已连接客户端推送运行数据。

## 3. 上电后的工作方式
设备上电后会自动进入主菜单，并默认处于自动模式。运行时，系统会持续完成三件事：

1. 采集光照和电流等传感器数据。
2. 根据当前模式判断是否需要清洁。
3. 更新 OLED 显示，并将状态同步到 Wi-Fi 客户端。

用户不需要频繁干预，主要通过按键切换模式和调整参数即可。

## 4. 按键操作
按键为 `UP / DOWN / ENTER / BACK` 四个按键。

- `UP`：上移光标、增加参数值。
- `DOWN`：下移光标、减少参数值。
- `ENTER`：进入子菜单、确认操作、保存参数。
- `BACK`：返回上一级、取消编辑。

菜单每屏只显示部分条目，使用 `UP / DOWN` 可以继续滚动查看。

### 参数编辑规则
进入数值项后，会进入编辑界面：

- `UP / DOWN` 调整数值。
- `ENTER` 保存并退出。
- `BACK` 放弃修改并恢复原值。

长按 `UP / DOWN` 时，数值会加速变化，适合快速调整。

## 5. 运行逻辑
系统的应用层逻辑可以理解为“采集 -> 判断 -> 执行 -> 显示/上报”：

1. 光照传感器采集当前光照强度。
2. INA226 采集当前电流、母线电压和分流电压。
3. 系统根据当前模式判断是否启动清洁。
4. 清洁启动后，电机按设定速度运行，达到设定时长后自动停止。
5. OLED 和 Wi-Fi 同步显示当前状态，便于现场查看和手机查看。

### 三种工作模式
- `AUTO` 自动模式
  - 系统根据光照和电流自动判断是否需要清洁。
  - 当光照达到设定阈值，同时实测电流低于预期值的一定比例，并且这种状态持续到设定确认时间后，系统才会启动清洁。
  - 夜间会自动禁止自动清洁。

- `MAN` 手动模式
  - 由用户手动触发开始或停止清洁。
  - 适合调试、测试或临时清洁。
  - 手动启动不受夜间锁定限制。

- `TIMER` 定时模式
  - 按设定的时间间隔自动清洁。
  - 如果到点时处于夜间，系统会先等待，等到白天再执行。
  - 适合固定维护场景。

清洁一旦开始，会持续到设定的清洁时长结束，或者由用户手动停止。

## 6. OLED 显示内容

### 6.1 Status 页面
这是最重要的运行页面，用于查看系统当前工作状态。

| 显示项 | 含义 |
| --- | --- |
| `M` | 当前模式，`AUTO` / `MAN` / `TIMER` |
| `S` | 当前清洁状态，`IDLE` 空闲、`RUN` 运行中、`PEND` 等待白天、`LOCK` 夜间锁定 |
| `L` | 光照百分比与原始值 |
| `I` | 当前实测电流 |
| `E` | 预估电流基准，用于自动判脏 |
| `Clean` | 本次清洁剩余时间，单位秒 |
| `T` | 定时任务剩余时间，单位秒 |
| `W` | Wi-Fi 状态，`LINK` 已有客户端连接、`AP` 热点已就绪、`FAIL` 初始化失败 |
| `N` | 夜间锁定标志，`1` 表示当前不允许自动/定时清洁 |
| `P` | 定时等待标志，`1` 表示到点但因夜间暂缓执行 |

### 6.2 Wi-Fi Info 页面
用于查看无线连接信息，方便手机端接入。

| 显示项 | 含义 |
| --- | --- |
| `SSID` | 设备热点名称 |
| `PASS` | 设备热点密码 |
| `HOST` | 热点地址 |
| `PORT` | TCP 服务端口 |
| `TXT` | 当前是否按周期推送状态数据 |
| `C` | 已连接客户端数量 |
| `S` | Wi-Fi 工作状态 |

### 6.3 Sensor Dbg 页面
这是调试页面，主要用于检查传感器和 INA226 是否正常。

| 显示项 | 含义 |
| --- | --- |
| `AO` | 光照原始值 |
| `DO` | 光照数字输出，高/低电平 |
| `B` | 母线电压 |
| `I` | 当前电流 |
| `Sh` | 分流电压 |
| `A` | 告警电平 |
| `R` | INA226 是否就绪 |
| `V` | INA226 数据是否有效 |
| `addr` | INA226 设备地址 |
| `S` | 当前诊断阶段 |
| `H` | 最近一次 HAL 状态 |
| `E` | 最近一次错误码 |

### 6.4 Edit Value 页面
进入可调参数后会看到当前参数值。该页面提示：

- `ENTER` 保存
- `BACK` 取消

## 7. 可调参数及作用

| 参数 | 默认值 | 作用 | 调整建议 |
| --- | --- | --- | --- |
| `Night Th` | 15% | 低于该光照值时判定为夜间，自动/定时清洁会被禁止 | 安装环境越暗，阈值可略调高；误判夜间则调低 |
| `Auto Th` | 40% | 自动模式下允许判脏的最低光照条件 | 光照不足时不要让系统误判为脏污 |
| `Max I` | 60.0 mA | 作为满光照下的预期电流参考，用于自动判脏 | 需要按实际光伏板规格校准，这是最关键参数 |
| `Dirty %` | 70% | 实测电流低于预期电流的多少比例时，认为可能脏污 | 数值越小越敏感，数值越大越保守 |
| `Confirm` | 10 s | 判脏条件持续多久后才真正启动自动清洁 | 用来抑制短时遮挡、波动和误触发 |
| `Interval` | 12 h | 定时清洁的时间间隔 | 适合按日常维护周期设置 |
| `Clean Sec` | 8 s | 每次清洁持续时间 | 过短可能清不干净，过长会增加耗电和磨损 |
| `Motor %` | 70% | 清洁电机运行速度/强度 | 现场试运行后再确定，避免过快或过慢 |

### 参数理解要点
- `Night Th` 和 `Auto Th` 不是同一个概念。
  - `Night Th` 用来判断“是否已经是夜间”。
  - `Auto Th` 用来判断“是否具备自动判脏的光照条件”。
- `Max I` 决定自动模式判断基准。
  - 设得过低，容易误判为脏。
  - 设得过高，可能一直判不出脏。
- `Dirty %` 和 `Confirm` 共同决定自动清洁的灵敏度。
  - 想更积极清洁，可以适当降低 `Dirty %`。
  - 想减少误触发，可以适当增加 `Confirm`。

## 8. 推荐使用流程
1. 上电后先进入 `Status` 页面，确认模式、光照、电流和 Wi-Fi 状态正常。
2. 先到 `Auto Set` 调整自动判定参数。
3. 再到 `Timer Set` 设置定时周期、清洁时长和电机速度。
4. 如需临时测试，进入 `Manual`，选择 `Start Clean` 或 `Stop Clean`。
5. 如需远程查看，手机连接 Wi-Fi 后读取设备推送的数据。

## 9. 项目需求对应说明
本项目与“基于 STM32 的光伏板清洁设备控制系统的设计”需求是一一对应的：

- `STM32 作为主控制器`：系统所有判断、显示和执行逻辑都由 STM32 完成。
- `实时监测光照和输出电流`：光照传感器和 INA226 共同提供判断依据。
- `自动清洁`：自动模式下根据光照与电流关系自动启动。
- `定时清洁`：定时模式支持按小时周期自动清洁。
- `夜间禁止清洁`：通过夜间阈值实现自动/定时任务屏蔽。
- `OLED 实时显示`：状态页、Wi-Fi 页和传感器调试页覆盖了运行观察需求。
- `按键设置参数`：支持模式切换、手动控制和参数修改。
- `手机端查看`：ESP8266 以热点方式提供 TCP 状态上报，手机可直接查看运行信息。

## 10. 现场使用建议
- 首次使用时，优先校准 `Max I`，再微调 `Dirty %` 和 `Confirm`。
- 如果夜间误触发，优先检查 `Night Th` 是否设置过低。
- 如果白天一直不自动清洁，优先检查 `Auto Th`、`Max I` 和 `Dirty %`。
- 如果到点但不清洁，查看 Status 页是否显示 `P=1`，这表示系统正在等待白天。
- 如果 Wi-Fi 或传感器异常，先看 `Wi-Fi Info` 和 `Sensor Dbg` 页面定位问题。
